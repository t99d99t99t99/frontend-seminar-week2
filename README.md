# 프론트엔드 세미나 2주차 과제

## 목표

리액트를 이용해 [2048 게임](https://specials.manoramaonline.com/Mobile/2022/2048-game/index.html)을 구현합니다.


## 설명

### 필수 구현사항

[x] 방향키로 조작이 가능해야 합니다.
[x] 128 타일이 생성되면 게임이 종료됩니다.

### 추가 구현사항

다음 중 두 가지를 선택하여 구현합니다.

[x] 새로고침을 해도 게임판이 유지되도록 하기 (난이도 하)
[x] 점수 표시하기 (난이도 중)
[x] Undo 버튼을 누르면 이전 턴의 상태로 돌아가게 하기 (난이도 중)
[x] 타일 이동 애니메이션 구현하기 (난이도 상)

### 기타

- 게임 로직의 구현에 도움을 드리기 위해 `map.ts` 파일을 넣어 두었습니다. `map.ts`를 그대로 사용하셔도 되고, 필요에 따라 수정하셔도 좋습니다.


## 주요 명령어

- `yarn dev` — 개발 서버를 실행합니다.
- `yarn check-all` — 타입, 포맷, 미사용 코드 검사를 실행합니다.
- `yarn build` — 프로덕션 빌드를 생성합니다.
